# سایت استاد حسین رضایتمند — نمونه‌های طراحی

سه نمونه‌ی طراحی برای انتخاب سبک سایت (نقاشی، خوشنویسی، مجسمه‌سازی، آثار نوشتاری):

| نمونه | فایل | حال‌وهوا |
|---|---|---|
| ۱ · شبِ گالری | `samples/1-shab-gallery.html` | موزه‌ای، مشکی و طلایی |
| ۲ · سپید | `samples/2-sepid.html` | مینیمال و مجله‌ای، روشن |
| ۳ · فیروزه | `samples/3-firouzeh.html` | ایرانیِ مدرن، لاجوردی و فیروزه‌ای |

صفحه‌ی `samples/index.html` هر سه را معرفی می‌کند. کافی است فایل را در مرورگر باز کنید.

## ساختار
- `src/` — سورس صفحه‌ها و `shared.js` (تولید آثار آزمایشی، گالری تمام‌صفحه، انیمیشن‌ها)
- `build.py` — `shared.js` را درون هر صفحه قرار می‌دهد و خروجی مستقل در `samples/` می‌سازد

```
python3 build.py
```

تصاویر آثار با کد و به‌صورت آزمایشی ساخته شده‌اند و در نسخه‌ی نهایی با عکس آثار واقعی جایگزین می‌شوند.

# ربات پست خودکار روزانه اینستاگرام (نیچ ترید طلا)

این پوشه یه پایپ‌لاین کامله که هر روز خودکار توی یه اجرا این‌ها رو پست می‌کنه:

| نوع محتوا | تعداد روزانه | فرمت |
|---|---|---|
| **ریلز** | ۱ | کلیپ استوک عمودی (Pexels) + هوک/نکته روی ویدیو + موزیک بدون کپی‌رایت |
| **استوری** | ۳ | عکس استوک (Pexels) + یه خط کوتاه برندی — بدون کپشن (محدودیت API، پایین‌تر توضیح داده شده) |
| **پست فید** | ۳ بار در هفته (دوشنبه/چهارشنبه/جمعه) | کارت عکس با هوک + نکته + دکمه CTA |

همه‌شون کپشن/متن با هشتگ چرخشی + دیسکلایمر ریسک دارن (به‌جز استوری که کپشن نداره). فایل نهایی چون Instagram API فقط از روی URL عمومی می‌خونه، به‌عنوان Release در همین گیت‌هاب آپلود می‌شه و از همون‌جا به Instagram Graph API داده می‌شه. وضعیت (چه کلیپ/عکس/هوک/خطی قبلاً استفاده شده) توی `state.json` ذخیره می‌شه تا تکراری نشه.

زمان‌بندیش با GitHub Actions انجام می‌شه (`.github/workflows/daily_post.yml`) — نیاز به سرور شخصی نداری. الان همه‌ی محتوای یه روز توی یه اجرای صبحگاهی منتشر می‌شه (استوری‌ها هم پشت‌سرهم)؛ اگه بعداً خواستی استوری‌ها در طول روز پخش بشن (مثلاً صبح/ظهر/شب)، باید cron رو به ۳ زمان جدا تقسیم کنیم — فعلاً برای سادگی این‌جوری نگهش داشتم.

> **نکته:** توضیحات بالا نسخه‌ی اولیه‌ست. الان پایپ‌لاین دو مرحله‌ایه (`generate` می‌سازه و منتظر تأیید می‌مونه، `publish` واقعی پست می‌کنه — `main.py` رو ببین)، دوشنبه/جمعه به‌جای پست فید ساده یه کارسل آموزشی کامل (`carousel_content.py`) می‌ره، و زمان‌بندی روزانه دیگه از GitHub cron نیست بلکه یه Routine که یه سشن Claude رو هر روز بیدار می‌کنه تا محتوا رو نشون بده و بعد از تأیید پابلیش کنه. پس‌زمینه‌ی عکس‌های کارسل/استوری/پست فید هم دیگه از Pexels نمی‌آد، بلکه از یه بانک عکس هنری ثابت (`backgrounds/`) که با هوش مصنوعی ساخته شده (`carousel_backgrounds.py`) — سبک بصری یکدستی داره.

> **محتوای ربات معامله‌گر:** دو تا کارسل جدید (`how-the-bot-works`, `bot-compatibility-and-license` در `carousel_content.py`) مستقیماً راجب خود ربات هستن — بر اساس اطلاعاتی که خودت دادی: اجرای کاملاً خودکار سیگنال‌های کانال تلگرام روی MT5، سازگاری با هر بروکر/پراپ‌فرم، پریست آماده‌ی XAUUSD، و لایسنس ۶ ماهه/۱ ساله با پشتیبانی کامل. چند خط استوری بوت-محور هم به `STORY_LINES` اضافه شد. همه‌ی این‌ها انگلیسی‌ان.

> **زبان محتوا بر اساس روز هفته:** طبق درخواستت، دوشنبه/چهارشنبه/جمعه همه‌ی محتوای اون روز (ریلز، ۵ استوری، پست فید یا کارسل) انگلیسیه؛ بقیه‌ی روزها (شنبه/یکشنبه/سه‌شنبه/پنج‌شنبه) کاملاً فارسیه — `ENGLISH_WEEKDAYS` تو `main.py`. برای فارسی از فونت Vazirmatn و چیدمان راست‌به‌چپ درست استفاده می‌شه (`text_overlay.py`)، و هر بانک محتوا یه نسخه‌ی `_FA` جدا داره: `content_bank.py` → `HOOKS_FA`/`TIPS_FA`/`CTAS_FA`/`DISCLAIMER_FA`/`STORY_LINES_FA`، و `carousel_content.py` → `CAROUSELS_FA` (ترجمه‌ی کامل و مستقل هر ۱۸ موضوع کارسل، با چیدمان راست‌به‌چپ در `carousel_composer.py`).

## پاسخ خودکار به کامنت‌ها

`reply_comments.yml` هر ۳۰ دقیقه یه‌بار خودکار اجرا می‌شه (این یکی cron واقعی داره، چون فقط از بین چندتا متن از‌قبل‌تأییدشده انتخاب می‌کنه، نه محتوای تازه‌ساز — نیازی به تأیید روزانه نداره). روی کامنت‌های پست‌های اخیر می‌گرده، زبان کامنت (فارسی/انگلیسی) رو تشخیص می‌ده، و با اسم کامنت‌گذار یه دعوت‌نامه‌ی رایگان به کانال تلگرام جواب می‌ده — قالب‌هاش تو `content_bank.py` (`COMMENT_REPLIES_EN` / `COMMENT_REPLIES_FA`) هستن، هر کدوم رو خواستی عوض کن.

⚠️ برای **لایک‌کننده‌ها** راهی نیست — Instagram API لیست لایک‌کننده‌ها رو اصلاً در اختیار نمی‌ذاره، فقط کامنت و دایرکت قابل پاسخ خودکارن (دایرکت فعلاً پیاده نشده، چون به یه webhook زنده نیاز داره، نه فقط اجرای دوره‌ای).

## قبل از هر چیز: تبدیل اکانت به Business/Creator

اکانت شخصی الان قابل اتصال به API نیست. این کار رو داخل اپ اینستاگرام انجام بده:

1. `Settings → Account type and tools → Switch to professional account`
2. نوع رو `Creator` یا `Business` انتخاب کن (برای فروش محصول، `Business` مناسب‌تره).
3. توی مراحلش بهت پیشنهاد می‌ده به یه **صفحه فیسبوک** وصلش کنی — این اجباریه، چون Graph API از طریق صفحه فیسبوک به اینستاگرام وصل می‌شه. اگه صفحه فیسبوک نداری، همون‌جا یکی بساز (رایگانه، نیازی نیست فالوور داشته باشه).

## ساخت اپ متا و گرفتن توکن

1. برو به [developers.facebook.com](https://developers.facebook.com/) و یه اپ جدید بساز (نوع: **Business**).
2. توی داشبورد اپ، محصول **Instagram Graph API** رو اضافه کن.
3. از ابزار [Graph API Explorer](https://developers.facebook.com/tools/explorer/) استفاده کن:
   - اپت رو انتخاب کن، خودت رو با فیسبوک لاگین کن.
   - پرمیژن‌های `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement` رو اضافه کن و یه **User Access Token** بگیر.
4. با همون توکن، `GET /me/accounts` رو بزن تا `id` صفحه فیسبوکت رو پیدا کنی.
5. با `page id`، بزن `GET /{page-id}?fields=instagram_business_account` تا **IG Business Account ID** رو پیدا کنی — این می‌شه `IG_USER_ID`.
6. توکن کوتاه‌مدتیه که گرفتی رو به یه **Long-Lived Token** (۶۰ روزه) تبدیل کن:
   ```
   GET /oauth/access_token?grant_type=fb_exchange_token&client_id={app-id}&client_secret={app-secret}&fb_exchange_token={short-lived-token}
   ```
   این می‌شه `IG_ACCESS_TOKEN`.

⚠️ **نکته مهم:** این توکن حداکثر ۶۰ روز اعتبار داره و باید دستی یا با یه اسکریپت جدا رفرش بشه، وگرنه ربات بعد از ۶۰ روز متوقف می‌شه. یه یادآور توی تقویم خودت بذار.

در حالت Development اپ، فقط اکانت‌هایی که به‌عنوان Tester/Admin به اپ اضافه کردی (یعنی خودت) کار می‌کنن — برای استفاده شخصی نیازی به App Review کامل متا نیست.

## گرفتن کلید Pexels

برو [pexels.com/api](https://www.pexels.com/api/) و رایگان یه API key بگیر → `PEXELS_API_KEY`.

## اضافه کردن موزیک

فایل‌های mp3 بدون کپی‌رایت رو بریز توی `instagram_bot/music/` (توضیح منابع رایگان توی `music/README.md` هست). بدون حداقل یه فایل، ربات ارور می‌ده و پست نمی‌کنه — عمداً همینه که یادت نره.

## تنظیم Secrets توی گیت‌هاب

برو `Settings → Secrets and variables → Actions → New repository secret` و این‌ها رو اضافه کن:

| Secret | مقدار |
|---|---|
| `IG_USER_ID` | همون Instagram Business Account ID |
| `IG_ACCESS_TOKEN` | Long-Lived Token |
| `PEXELS_API_KEY` | کلید Pexels |

(`GITHUB_TOKEN` نیازی به ست کردن دستی نداره — GitHub Actions خودکار می‌سازتش.)

## شخصی‌سازی انجام‌شده

- `BRAND_HANDLE` توی `main.py` رو به `@Goldhamedsignals` تنظیم کردم.
- همه‌ی CTAها توی `content_bank.py` به «Telegram channel در بیو + امکان دایرکت» اشاره می‌کنن و به‌جای فروش یک‌باره، از عبارت «۶-month & 1-year subscription» استفاده می‌کنن (چون قرارداد فروشت اشتراکیه، نه خرید قطعی).
- هشتگ برند به `#goldhamedsignals` تنظیم شد.
- فعلاً همه‌ی محتوا انگلیسیه؛ اگه بعداً خواستی یه پست فارسی هم اضافه کنی، بگو تا یه نسخه‌ی جدا (مثلاً `content_bank_fa.py` + سوییچ توی `main.py`) براش بسازم — فعلاً چون گفتی «شاید بعضی وقت‌ها»، این بخش رو نساختم که کد الکی پیچیده نشه.

## بقیه‌ی تنظیمات دستی

- زمان‌بندی cron توی `.github/workflows/daily_post.yml` (الان `15:00 UTC`) رو با بهترین ساعت فعالیت مخاطب‌هات تنظیم کن.
- اگه تعداد پست/استوری در هفته رو می‌خوای عوض کنی، توی `main.py` مقادیر `STORIES_PER_DAY` و `FEED_POST_WEEKDAYS` رو تغییر بده.

## اجرای محلی (برای تست قبل از فعال کردن cron)

```bash
cd instagram_bot
pip install -r requirements.txt
export IG_USER_ID=...
export IG_ACCESS_TOKEN=...
export PEXELS_API_KEY=...
export GITHUB_TOKEN=...            # یه Personal Access Token با scope مخزن
export GITHUB_REPOSITORY=owner/repo
python main.py
```

## محدودیت‌ها و نکات مهم

- **موزیک رسمی اینستاگرام (Reels audio library) از طریق API قابل انتخاب نیست** — به همین خاطر موزیک از قبل داخل خود فایل ویدیو میکس می‌شه (روش قانونی و پایدارتر).
- **استوری‌ها از طریق API کپشن یا استیکر تعاملی (نظرسنجی، لینک سوایپ‌آپ) ندارن** — فقط عکس/ویدیوی ساده با متن روی خودش. برای استیکر واقعی باید دستی از اپ اینستاگرام بذاری.
- Content Publishing API محدودیت نرخ داره (حدود ۲۵ پست در ۲۴ ساعت برای هر اکانت) — با کادانس فعلی (۱ ریلز + ۳ استوری + گاهی ۱ پست فید = حداکثر ۵ در روز) خیلی زیر این سقفیم.
- چون Actions فقط روی برنچ پیش‌فرض (`main`) طبق زمان‌بندی cron اجرا می‌شه، بعد از مرج این تغییرات به `main`، زمان‌بندی خودکار فعال می‌شه؛ تا قبلش فقط با دکمه‌ی «Run workflow» (workflow_dispatch) توی تب Actions قابل تست دستیه.
- محتوای مرتبط با ترید/فروش ربات معامله‌گر ممکنه هدف بازبینی‌های سیاست تبلیغات مالی متا قرار بگیره؛ به همین دلیل دیسکلایمر ریسک توی هر کپشن اجباریه — لطفاً حذفش نکن و از ادعای «سود تضمینی» پرهیز کن (توجه: استوری‌ها کپشن ندارن، پس دیسکلایمر فقط روی ریلز و پست فید میاد — اگه لازمه می‌تونی متن دیسکلایمر رو داخل خود تصویر استوری هم اضافه کنی).
- **پسورد اینستاگرام هیچ‌جای این پروژه لازم نیست و نباید جایی وارد بشه** — فقط `IG_ACCESS_TOKEN` که از OAuth رسمی متا می‌گیری.

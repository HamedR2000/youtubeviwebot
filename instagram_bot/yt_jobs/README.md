# یوتیوب ← ریلز + کارسل اینفوگرافیک

هر ویدیوی یوتیوب یه پوشه‌ی جدا اینجا داره: `yt_jobs/<video_id>/`. کافیه لینک ویدیو رو توی سشن Claude بفرستی؛ بقیه‌ش این‌جوری پیش می‌ره:

| مرحله | کی انجامش می‌ده | فایل |
|---|---|---|
| ۱. ثبت لینک | Claude | `job.json` → `{"url": "...", "lang": "fa"}` |
| ۲. گرفتن متن ویدیو (زیرنویس) | GitHub Actions (`yt_to_reel.yml`) | `transcript.json` |
| ۳. خلاصه‌کردن نکات ترید به اسلاید | Claude، از روی transcript | `content.json` |
| ۴. ساخت کارسل ۴:۵ + ریلز ۱ تا ۲ دقیقه‌ای با موزیک پس‌زمینه | GitHub Actions | `result.json` (لینک‌ها + `manifest_url`) |
| ۵. پیش‌نمایش و تأیید | تو | — |
| ۶. انتشار | `daily_post.yml` با `mode=publish` و همون `manifest_url` | — |

اگه یه مرحله خطا بده، متنش توی `error.txt` همون پوشه نوشته می‌شه. با تغییر `content.json` و push دوباره، فقط رندر از نو انجام می‌شه (فایل‌های قبلی روی همون Release جایگزین می‌شن).

## ساختار `content.json`

```jsonc
{
  "lang": "fa",                       // "fa" (راست‌به‌چپ، Vazirmatn) یا "en"
  "theme": "dark",                    // "dark" یا "light"
  "category": "خلاصه‌ی ویدیو",          // برچسب بالای همه‌ی اسلایدها
  "voiceover": false,                 // پیش‌فرض: بدون گوینده، فقط موزیک؛ true = با گوینده
  "tts": "auto",                      // auto | elevenlabs | openai | edge (بخش «صدای گوینده» پایین)
  "voice": "fa-IR-FaridNeural",       // فقط برای edge؛ یا fa-IR-DilaraNeural (صدای زن)
  "voice_rate": "+0%",                // فقط برای edge
  "caption": "متن کپشن (دیسکلیمر و هشتگ خودکار اضافه می‌شن)",
  "hashtags": ["#..."],               // اختیاری
  "slides": [                          // حداکثر ۱۰ اسلاید (محدودیت کارسل اینستاگرام)
    {"type": "cover", "kicker": "...", "title": [["خط سفید", "white"], ["خط طلایی", "gold"]],
     "subtitle": "...", "chips": [{"icon": "bulb", "text": "۵ نکته"}],
     "narration": "متنی که گوینده روی این اسلاید می‌خونه"},
    {"type": "point", "number": 1, "label": "نکته ۱ از ۵", "title": "...",
     "narration": "...",
     "bullets": [{"icon": "shield", "text": "متن روی صفحه", "say": "متن گوینده (اختیاری)"}],
     "highlight": {"value": "1:2", "label": "..."},     // اختیاری
     "takeaway": "...", "takeaway_say": "..."},          // اختیاری
    {"type": "summary", "title": "جمع‌بندی", "items": ["...", "..."], "narration": "..."},
    {"type": "cta", "title": "...", "text": "...", "handle": "@Goldhamedsignals",
     "actions": [{"icon": "document", "text": "سیو کن"}], "note": "...", "narration": "..."}
  ]
}
```

آیکون‌ها: `check`, `warning`, `bulb`, `stop`, `trend_up`, `shield`, `globe`, `coins`, `search`, `document`, `gear`, `bar_chart`, `clock`, `target`, `scale`, `arrows_swap`, `person_plus`.

توی ریلز، هر اسلاید `point` مرحله‌به‌مرحله ظاهر می‌شه (اول عنوان، بعد هر بولت، بعد جمع‌بندی اون نکته) و هر مرحله به اندازه‌ی زمان خوندن متن روی صفحه‌ش می‌مونه؛ کل ریلز هم خودکار توی بازه‌ی ۶۰ تا ۱۲۰ ثانیه جا داده می‌شه. فیلدهای `narration`/`say` فقط وقتی گوینده روشنه استفاده می‌شن.

توی ریلز هیچ شماره‌گذاری «چند از چند» نمیاد (شمارنده‌ی بالا، نقطه‌های پایین و «نکته ۱ از ۷»)؛ این‌ها فقط روی اسلایدهای کارسل هستن.

## صدای گوینده (اختیاری)

ریلزها به‌طور پیش‌فرض بدون گوینده و فقط با موزیک ساخته می‌شن و هر مرحله به اندازه‌ی زمان خوندن متنش روی صفحه می‌مونه. اگه یه وقتی گوینده خواستی، `"voiceover": true` بذار. صدای رایگان (edge-tts مایکروسافت) فارسی رو با لهجه و رباتیک می‌خونه. برای صدای طبیعی، یکی از این‌ها رو به Secretهای ریپو اضافه کن؛ از اجرای بعدی خودکار استفاده می‌شه (`yt_tts.py`):

| سرویس | Secretها | توضیح |
|---|---|---|
| **ElevenLabs** (پیشنهادی) | `ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID` | از Voice Library یه صدای فارسی‌زبان بومی انتخاب کن و Voice ID‌ش رو بردار. طبیعی‌ترین نتیجه. |
| **OpenAI** | `OPENAI_API_KEY` | مدل gpt-4o-mini-tts با دستور «فارسی محاوره‌ای تهرانی»؛ از edge خیلی بهتره، ولی ممکنه یه کم لهجه داشته باشه. |

## اگه یوتیوب جلوی گرفتن زیرنویس رو گرفت

یوتیوب گاهی IPهای سرورهای ابری (از جمله GitHub Actions) رو برای زیرنویس بلاک می‌کنه. اون موقع یکی از این دو Secret رو اضافه کن: `YT_PROXY_URL` (یه پراکسی http) یا `YT_COOKIES` (خروجی cookies.txt مرورگر از یه اکانت یوتیوب **غیرشخصی**). یا خیلی ساده‌تر: متن/زیرنویس ویدیو رو مستقیم توی چت برام بفرست.

## نکته‌ی کپی‌رایت

خروجی از تصاویر خود ویدیوی یوتیوب استفاده نمی‌کنه — فقط نکات آموزشیش با طراحی و صدای خودمون بازگو می‌شه، و به منبع هم توی خروجی اشاره نمی‌شه. این هم از نظر کپی‌رایت امن‌تره، هم الگوریتم اینستاگرام محتوای اوریجینال رو بیشتر پخش می‌کنه.

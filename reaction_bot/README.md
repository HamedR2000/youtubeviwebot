# پایپ‌لاین ری‌اکشن ویدیو (اینستاگرام → یوتیوب Shorts)

دو تا مسیر برای رسیدن به یه ویدیوی نهایی روی یوتیوب هست:

1. **`main.py`** — از صفر می‌سازه: لینک اینستاگرام رو می‌گیره، با عکس آواتار (بدون هیچ متنی روی صفحه) ترکیب می‌کنه، فرمت عمودی Shorts.
2. **`publish_ready.py`** — تصمیم فعلی: خودت ویدیوی نهایی رو (مثلاً خروجی HeyGen، با آواتار واقعی و لب‌سینک) از بیرون می‌سازی و آماده میاری؛ این اسکریپت فقط نوار سابسکرایب/لایک رو ته‌ش اضافه می‌کنه و آپلود می‌کنه — نیازی به دانلود از اینستاگرام یا ساخت آواتار نداره.

هر دو از همون بخش «راه‌اندازی یوتیوب» و همون `youtube_upload.py` استفاده می‌کنن.

## جریان کار فعلی: ویدیوی آماده (HeyGen) -> یوتیوب

```bash
cd reaction_bot
pip install -r requirements.txt

# قدم ۱: ببین همه‌چیز درسته (ابعاد، مدت) -- بدون --approve چیزی ساخته/آپلود نمی‌شه
python publish_ready.py --video path/to/heygen_video.mp4 --title "عنوان ویدیو"

# قدم ۲: نوار سابسکرایب/لایک اضافه می‌شه، فایل توی workdir/outputs/ می‌مونه
python publish_ready.py --video path/to/heygen_video.mp4 --title "عنوان ویدیو" --approve

# قدم ۳: وقتی راضی بودی، آپلود کن (پیش‌فرض private -- خودت از یوتیوب استودیو تصمیم انتشار نهایی رو بگیر)
python publish_ready.py --video path/to/heygen_video.mp4 --title "عنوان ویدیو" --approve --upload --privacy unlisted
```

- خودش هشدار می‌ده اگه ویدیو عمودی نباشه یا بیشتر از ۳ دقیقه باشه (محدودیت Shorts).
- خودکار `#Shorts` رو به description اضافه می‌کنه (اگه از قبل نبود).
- `--no-banner` بده اگه نمی‌خوای نوار سابسکرایب/لایک اضافه بشه.

## جریان کار main.py (ساخت از صفر با لینک اینستاگرام)

```bash
cd reaction_bot
pip install -r requirements.txt   # نیاز به ffmpeg هم هست: apt install ffmpeg

# قدم ۱: کلیپ رو دانلود کن و پیش‌نمایش بگیر (بدون --approve چیزی ساخته نمی‌شه)
python main.py --source "https://www.instagram.com/reel/XXXXX/"

# قدم ۲: وقتی مطمئن شدی، همون دستور رو با --approve بزن تا ویدیوی نهایی ساخته بشه
python main.py --source "https://www.instagram.com/reel/XXXXX/" --approve

# قدم ۳: بعد از دیدن فایل خروجی (workdir/outputs/) اگه راضی بودی، آپلود کن
python main.py --source "https://www.instagram.com/reel/XXXXX/" --approve --upload --privacy unlisted
```

- `--source` هم لینک اینستاگرام قبول می‌کنه (با `yt-dlp` دانلود می‌شه — فقط برای پست‌های عمومی جواب می‌ده) هم مسیر یه فایل ویدیویی محلی که خودت از قبل ذخیره کردی.
- `--script`/`--script-file` اختیاریه — چون روی ویدیو نمایشی نداره، فقط برای یادداشت/عنوان پیش‌فرض یوتیوب و کارهای بعدی (مثلاً وقتی صدا/TTS اضافه شد) نگه داشته می‌شه.
- بدون `--approve` فقط دانلود و پیش‌نمایش انجام می‌شه و متوقف می‌شه.
- بدون `--upload` فایل نهایی توی `workdir/outputs/` می‌مونه تا خودت قبل از پابلیک شدن نگاهش کنی؛ آپلود کاری نیست که خودکار/بی‌سروصدا انجام بشه.
- پیش‌فرض `--privacy` روی **`private`**ه (نه public) — عمداً همینه، تا خودت از یوتیوب استودیو تصمیم نهایی انتشار رو بگیری. برای انتشار مستقیم باید صریحاً `--privacy public` یا `--privacy unlisted` بدی.
- `--dry-run` (کنار `--upload`) فقط چیزی که قراره به یوتیوب فرستاده بشه رو چاپ می‌کنه، هیچی واقعاً آپلود نمی‌شه — برای تست.

## چیدمان ویدیوی خروجی

بوم عمودی ۱۰۸۰×۱۹۲۰ (۹:۱۶، مناسب Shorts):
- **بالای صفحه (~۶۰٪ ارتفاع، قابل تنظیم با `REACTION_SOURCE_HEIGHT_RATIO`):** کلیپ منبع، کراپ‌شده تا این ناحیه رو پر کنه — **تمام صفحه نیست**، طبق نکته‌ی ریسک کپی‌رایت.
- **پایین صفحه:** فقط عکس آواتار (اگه بدی)، وسط‌چین، بدون هیچ متن/بج/کپشنی.
- صدای کلیپ منبع نگه داشته می‌شه؛ اگه `--voice path/to/audio.mp3` بدی (ضبط خودت یا خروجی TTS)، اون رو روی صدا میکس می‌کنه و صدای منبع رو کم می‌کنه (duck) — فعلاً چون تصمیم گرفتی بدون صدا کار کنیم، این پارامتر اختیاریه و به آواتار سینک نمی‌شه.

**آینده:** خودت گفتی می‌خوای این آواتار واقعاً به ویدیو بخنده/واکنش نشون بده، نه فقط عکس ثابت با نوسان. این یه تصمیم جدا نیاز داره (مثلاً چندتا عکس با حالت‌های مختلف که بین‌شون سوییچ کنیم، یا یه انیمیشن/ویدیوی واقعی) — هروقت خواستی روش کار کنیم بگو.

## آواتار ری‌اکشن

پایپ‌لاین خودش کاراکتر تولید نمی‌کنه — فقط یه عکس آماده رو وسط پایین صفحه می‌ذاره و بهش یه نوسان ملایم بالا/پایین می‌ده (چون فعلاً صدا/لب‌سینک نداریم). کاراکتر فعلی: یه پسر خوش‌خنده، مشخصاً روی ویلچر نشسته، ساخته‌شده با Bing Image Creator (سبک عکس واقعی، نه کارتون) و ذخیره‌شده توی `reaction_bot/assets/avatar.png`.

عکسی که خودت با AI ساختی و آپلود کردی پس‌زمینه‌ی معمولی (اتاق نشیمن) داشت؛ من با `rembg` (ابزار حذف پس‌زمینه‌ی محلی/رایگان) پس‌زمینه رو حذف کردم و تصویر رو تنگ دور خودِ پسر/ویلچر کراپ کردم تا روی پس‌زمینه‌ی تیره‌ی ری‌اکشن تمیز بشینه.

**اگه خواستی یه عکس دیگه/پوز دیگه بسازی:** همون ابزارها (Bing Image Creator، Leonardo.Ai، Midjourney) با همون پرامپت قبلی جواب می‌دن. فایل جدید رو جایگزین `assets/avatar.png` کن (پس‌زمینه‌ش هرچی بود مهم نیست، دوباره پردازشش می‌کنم) — یا موقتاً با `--avatar path/to/file.png` تستش کن بدون این‌که فایل پیش‌فرض رو عوض کنی.

**نکته‌ی چیدمان:** اندازه‌ی نمایش آواتار به‌صورت خودکار به ارتفاع/عرض صفحه محدود می‌شه تا کش نیاد، حتی اگه عکس منبع نسبت‌ابعاد متفاوتی داشته باشه (مثلاً ویلچر کنارش باشه).

## تدوین سبک (مقدمه/پایان‌بندی/زوم) -- `edit.py`

قبل از اینکه فایل رو بدی `publish_ready.py` (بخش بالا)، می‌شه ازش رد کرد تا:
- یه کارت متنی مقدمه قبل ویدیو اضافه بشه (چند ثانیه)
- یه کارت متنی پایان‌بندی («نظر شما چیه؟») بعد ویدیو اضافه بشه
- یه زوم ملایم («punch-in») روی یه بازه‌ی زمانی خاص از ویدیوی اصلی بیفته، برای تأکید روی یه لحظه‌ی بامزه

```python
from edit import add_intro_outro
add_intro_outro(
    "raw_video.mp4", "edited.mp4",
    intro_text="این اتفاق امروز توی فضای مجازی ایران وایرال شد...",
    outro_text="نظر شما چیه؟",
    zoom_at=(8.5, 12.0),  # ثانیه‌ی شروع و پایان زوم
)
```

**محدودیت مهم:** تبدیل گفتار-به-متن (STT) توی این محیط در دسترس نیست -- مدل‌های Whisper از huggingface.co و openaipublic.azureedge.net دانلود می‌شن که هر دو با سیاست شبکه‌ی این سرور مسدودن. یعنی:
- نمی‌شه زیرنویس واقعی (کلمه‌به‌کلمه‌ی حرفی که زده می‌شه) خودکار ساخت.
- کامنت/هایلایت/زمان زوم بر اساس **دیدن فریم‌های تصویری** انتخاب می‌شه (نه شنیدن صدا) -- یعنی هر ویدیو رو دستی نگاه می‌کنم تا لحظه‌ی مناسب زوم رو پیدا کنم، نه یه اسکریپت کاملاً خودکار.
- اگه خودت متن حرف‌های ویدیو رو بدی، می‌شه زیرنویس واقعی هم بهش اضافه کرد.

## نوار سابسکرایب/لایک

`branding.py` یه نوار همیشگی (کل مدت ویدیو) به پایین صفحه اضافه می‌کنه، با متن «سابسکرایب کن و لایک رو یادت نره». `publish_ready.py` خودکار صداش می‌زنه؛ اگه `main.py` استفاده می‌کنی و می‌خوای همون نوار روی خروجی‌هاش هم باشه بگو تا اضافه‌ش کنم (فعلاً فقط توی مسیر `publish_ready.py` وصله). متن/استایلش رو هم هروقت خواستی عوض کن، `branding.py` رو ببین.

## راه‌اندازی یوتیوب (OAuth)

آپلود از طریق YouTube Data API v3 با اکانت خودته، نه پسورد. چون این پروژه روی یه سرور ابری بدون مرورگر اجرا می‌شه، فلوی معمول (باز شدن خودکار مرورگر) جواب نمی‌ده -- به‌جاش یه فلوی دستی یک‌باره داریم:

1. برو به [Google Cloud Console](https://console.cloud.google.com/) و یه پروژه بساز (یا از پروژه‌ی موجود استفاده کن).
2. از `APIs & Services → Library`، **YouTube Data API v3** رو فعال کن.
3. از `APIs & Services → OAuth consent screen`، نوع رو `External` بذار (کافیه خودت رو به‌عنوان test user اضافه کنی، نیازی به تأیید گوگل برای استفاده‌ی شخصی نیست).
4. از `APIs & Services → Credentials → Create Credentials → OAuth client ID`، نوع اپ رو **Desktop app** انتخاب کن و بسازش.
5. JSON دانلودش کن، به اسم `reaction_bot/client_secret.json` ذخیره‌اش کن و برام بفرست (مثل عکس آواتار، از طریق آپلود گیت‌هاب یا فایل ضمیمه‌ی چت).
6. من `python oauth_setup.py --print-url` رو اجرا می‌کنم و یه لینک بهت می‌دم؛ توی مرورگر خودت بازش کن، با اکانت یوتیوبت وارد شو، اجازه بده.
7. صفحه‌ی بعدی ارور «نمی‌شه وصل شد» می‌ده -- عادیه. آدرس کامل همون صفحه رو از نوار آدرس کپی کن و برام بفرست.
8. من `python oauth_setup.py --exchange "همون آدرس"` رو می‌زنم و توکن (`reaction_bot/token.json`) ذخیره می‌شه -- فقط همین یه‌بار لازمه، بعدش هر چقدر بخوای بدون تکرار این مراحل آپلود می‌کنم (`client_secret.json` و `token.json` هر دو توی `.gitignore` هستن، هیچ‌وقت کامیت نمی‌شن، چون کلیدهای حساسن).

⚠️ **محدودیت quota:** پروژه‌ی جدید گوگل روزانه ۱۰,۰۰۰ واحد quota پیش‌فرض داره و هر آپلود ویدیو ~۱۶۰۰ واحد مصرف می‌کنه — یعنی حدود **۶ آپلود در روز**. برای بیشتر باید از همون Cloud Console درخواست افزایش quota بدی (فرم "Quotas" → YouTube Data API؛ چند روز طول می‌کشه تا گوگل جواب بده).

## نکات حقوقی/ریسک (رعایت‌شده در این پیاده‌سازی)

- کلیپ منبع همیشه فقط بخشی از فریم رو می‌گیره (پیش‌فرض ۶۰٪ ارتفاع)، نه تمام صفحه.
- بخش ری‌اکشن (آواتار) جای واقعی و قابل‌توجه روی صفحه داره (نه یه لوگوی کوچیک تو گوشه) تا واکنش بخش محسوسی از ویدیو باشه، نه صرفاً بازپخش خام.
- توصیه‌ی پروژه: توی توضیحات ویدیوی یوتیوب همیشه به صاحب کلیپ اصلی کردیت بده (نام/آیدی اینستاگرام) — فیلد `--description` برای همینه.
- دانلود از اینستاگرام (`yt-dlp`) فقط برای محتوای عمومی جواب می‌ده و طبق ToS اینستاگرام باید با احتیاط استفاده بشه؛ این ابزار مسئولیت انتخاب و اجازه‌گیری از منبع رو خودکار نمی‌کنه.

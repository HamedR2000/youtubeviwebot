Privacy Policy

Doodle Pals Uploader — last updated November 10, 2026

What this application is

Doodle Pals Uploader is an internal tool used only by the owner of the Doodle Pals YouTube channel to upload the channel's own original videos. It has no other users and no public sign-up.

YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed and how it is used

  • With the owner's permission, the application uploads videos, titles, descriptions and tags to the owner's own YouTube channel.
  • It reads only the basic name and ID of the authorized channel, to confirm that uploads go to the correct channel.
  • It does not read, collect, sell or share any data about viewers, children or any other person.

Storage and security

The OAuth authorization token is stored only as an encrypted secret in the channel owner's private automation settings and is used only to upload the owner's videos. The only YouTube data kept is the list of IDs of our own uploaded videos, for our upload records. No personal data is stored anywhere else, and no data is shared with or sold to third parties.

Data retention and deletion

  • Stored upload records (our own video IDs) are kept only as long as needed for the channel's records.
  • Revoking access deletes the application's ability to access the account. Access can be revoked at any time from Google security settings (third-party access).
  • When access is revoked, or on request, the stored authorization token and upload records are deleted within 7 days.
  • Deletion requests can be sent through the contact details on the Doodle Pals YouTube channel's About page.

Children

Doodle Pals videos are marked as "made for kids" on YouTube. This application does not collect any information from children.

Contact

Questions can be sent through the contact details on the Doodle Pals YouTube channel's About page.
